## Toolbar

Two switches in the toolbar change the whole canvas at once:

- **Brand** — `jit` is the default. A brand swaps only the semantic layer through `[data-theme]`, so no component carries brand code.
- **Scheme** — light or dark. Dark is Storybook-only for now: `.storybook/dark.css` mirrors the semantic colors, and the kit itself has no dark tokens yet.

Every component should look right in all four combinations. Check them before you ship a change.

## Where shadcn differs

The kit uses shadcn names and props wherever a shadcn equivalent exists. The names
that now match are Button `default`, `outline` and `secondary`, Alert `variant`
(`default`, `destructive`), Tabs `default`, and the `empty-icon` and `slider-range`
slots. Code written for shadcn should work with those names unchanged.

Where the two differ, the kit follows Figma. Each difference falls into one of four kinds:
